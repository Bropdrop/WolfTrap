# Candidate review for NS-NEURON-001

**Historical prepublication review.** The private candidate `0.3.0a1+ns.neuron.1` reproduced all eight held-out cases through both the source and installed console entry points. The reviewer’s independent archive build produced SHA-256 `ff4868ad7248e1135821eab3d1af3145185a32c0fa66c436d15b0046b8ec1456`. No open blocking findings. Owner release review was pending when this assessment was written. The reviewer was a separate agent in the same Codex session, with access to the original protocol, source and evidence. This review confers no external scientific or publication approval.

## Source, inputs and selection

I compared all 90 members of the recovered source tree directly with the owner ZIP and all 21 pilot members with its supplied ZIP. Every file matched. In the candidate, 84 historical files remain at their original paths byte for byte. Five existing files changed to expose the command, identify the private version, package the new files and describe the addition. The original bundle inventory moved intact to `historical/`. All 42 historical files across the example runs and pretrained/attention summaries stayed byte-identical. The qualified 17,332-byte pilot module also matched its source exactly. A temporary fresh-process rebuild verified all 97 source-archive entries and every payload digest in the new manifest. [Source comparison](review-source-delta.json) · [Archive rebuild](review-archive.json)

The integration calls the recovered seven-file size and hash check before model loading. The pilot rechecks the inventory and uses local safetensors, a concrete GPT2LMHeadModel and a tokenizer with remote code disabled. Torch is imported only after dispatch to the neuron command. I exercised version, help and incomplete inventory in a NumPy-only environment under the network-denying launcher. Invalid input returned a non-success disposition before creating the evidence directory. The live studies also ran under the offline launcher. [CLI smoke check](review-cli-smoke-002.json) · [Model acquisition receipt](../acquisition/model-attempt-001/summary.json)

I inspected the source path from protocol generation to the held-out loops. All template token IDs are declared up front. Discovery uses only the four France discovery prompts. It ranks all 18,432 neurons, tests the top eight by exact last-position ablation, and writes the winner, six same-layer control IDs and six equal-norm direction vectors before any held-out forward pass. The results bind this selection by SHA-256, and the selection binds protocol and discovery. Each validation case measures the ablation and six neuron controls, then the selected and six control directions at each of six layers. The same file implements both the qualified standalone and integrated measurement.

## Test and measurement evidence

* The recovered suite passed all 194 unique test IDs. The candidate passed those same 194 IDs plus 15 pilot tests and five CLI tests. All 214 per-case entries reported success. The source snapshots before and after each suite matched. [Recovered 194](tests/recovered-002/summary.json) · [Candidate 214](tests/candidate-001/summary.json) · [Per-test outcomes](tests/candidate-001/per-case.json)
* I independently compared the four original JSON byte streams and reconstructed the per-case measures for the source entry point and the installed wheel. Both candidate runs matched the standalone protocol, discovery, frozen selection and results exactly. All eight prompts, control effects, directions at all six layers, and original mechanism limits matched. The source and installed commands generated the same NeuralScope seal. [Source-entry results](review-per-case.json) · [Installed-entry results](review-installed-per-case.json) · [Installed wheel receipt](tests/wheel-001/summary.json)
* The empirical qualification is limited to this checkpoint and finite Paris/Berlin contrast. The selected neuron was L0 N874. Exact ablation lowered the target-minus-foil margin on two of four France prompts and one of four Germany prompts. The expected city ranked first on zero of eight baselines. The independent raw-array work includes a separate implementation and per-prompt full-logit comparisons. Source hashes and signedness of effects alone cannot establish mechanism or generalization. [Mechanism and per-prompt evidence](../pretrained/README.md) · [Cross-engine comparison and replay](../cross-engine/README.md)
