What was measured

For each matched pair, the runner recorded the model's internal activations, copied one selected component from the clean run into the changed run, and measured the target answer's logit margin. It also applied the reverse patch, self patches, and zero ablation. Patches affect only the predeclared token positions.

A normalized restoration of 1 means this patch recovered the clean-to-changed logit gap for this pair. Zero means it recovered none. This value is not a probability; it can be negative or exceed 1.

Reading this result correctly

  • Finite chosen cases do not certify a model or reveal private beliefs or intentions.
  • Interventions establish effects within this computation and input setup.
  • Zero ablation may move internal activity outside the model's usual distribution.
  • Normalized effects are not probabilities and are not clipped to [0, 1].
  • Validation inputs are predeclared; related synthetic cases are not independent population samples.

Reproducible evidence

The bundle includes the exact model tensors and configuration, paired token inputs, numerical traces, metrics, code hashes, environment versions, and a closed inventory receipt.
