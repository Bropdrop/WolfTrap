# DistilGPT2 adapter design review

This pre-execution technical review records the adapter behaviors and the checks specified for the pinned checkpoint. The installed audit and subsequent experiments provide the empirical measurements. [Installed audit](POST_ACQUISITION.md)

## Static trace through the historical harness

| Area | Source behavior | Empirical evidence still required on the checkpoint |
|---|---|---|
| Identity and loading | Lines 11–35 and 153–159 require exactly the seven pinned basenames and recompute their digests. The loader uses the named GPT2LMHeadModel class, local-only lookup, safetensors, eager attention, float32 and eval mode. Tokenizer loading disables remote code. The runtime checks model type and a parameter count of 81,912,576. | Confirm the immutable local snapshot and reviewed package versions. Check actual loader diagnostics, missing or unexpected weights, six blocks and 3,072 neurons per projection. The protocol cites pin constants. The adapter hashes inputs once, before load. The offline flags control library behavior and do not measure OS-level isolation. |
| Tokens and alignment | Lines 160–169 encode the space-prefixed target and foil once, requiring a single ID each. The later margin check also requires distinct, in-range IDs. The four templates per split are paired across France and Germany. Each group pads on the left with EOS. The real tokens have mask 1 and positions 0 through length minus one. The last column is always a real token. | Verify texts and IDs with the pinned tokenizer, including the initial space on each candidate. For each prompt compare the complete vocabulary logits at every real token between its unpadded single forward and the corresponding tail of the padded batch. Repeat for the ablation. Padding columns have no single-prompt counterpart. |
| Projection and scoring | Lines 65–70, 111–130 and 185–189 use each block's output projection. The final-token activation is the tensor entering that projection. The screen score is that activation times the dot product of its weight row with the downstream target-minus-foil margin gradient. The gradient of the sum gives per-prompt gradients if forward evaluation does not mix batch members. | Confirm that the actual checkpoint module uses the expected post-activation input and weight layout of 3,072 input rows by 768 output columns. Check the numerical reconstruction against actual outputs for each block. The source's initial shape guard only checks rank and bias width. |
| Selection and split | Lines 181–197 score discovery-positive prompts, sort all candidates by descending signed mean prediction, exactly ablate the top eight and select the highest exact mean strictly above 0.0001. Layer and neuron ascending break ties. The discovery-control prompts are recorded. The protocol, discovery inventory, selected row, sign, magnitude, control IDs and control vectors are written before the first held-out forward. | Confirm 18,432 unique layer/neuron pairs, exact shortlist and winner from the actual run. Verify the protocol and discovery SHA-256 links carried by the selection and the selection link in results. A no-selection outcome returns before validation. The split separates templates while sharing countries and target IDs. The historical procedure has no external preregistration. |
| Causal ablation | Lines 90–109 and 171–179 zero only the last-position post-activation. The comparison adds minus the original activation times the same projection row at the projection output. Bias is common to both routes. Both run the remaining network. Their maximum difference spans the complete logits tensor. | Compare both intervention routes per prompt against the padded calculation. Retain arrays for relevant pre- and post-projection states and full logits. A margin or argmax alone can conceal other vocabulary differences. |
| Frozen controls and cross-layer measurements | Lines 193–203 sample six distinct same-layer neurons excluding the selection. The chosen vector points along the signed row. Its norm uses the row norm times the discovery median absolute activation (Torch's lower median for an even sample). Six Gaussian vectors from a dedicated generator are normalized to this same magnitude. Every layer receives the same chosen vector and six controls. The reported chosen effect is injected minus baseline margin. The ablation effect is baseline minus ablated margin. | Verify sign and size, control identities, vector norms, per-prompt values and each layer's chosen-minus-control arithmetic. Random neurons are matched by layer only. The cross-layer intervention measures sensitivity to the injected vector at each site. It does not isolate an endogenous neuron contribution at every layer. |
| Numerical checks, exit and replay | Lines 171–179 and 197–223 compare unhooked and hooked logits, no-op injection, restored logits, projection reconstruction, ablation versus subtraction and autograd versus symmetric finite differences. A failed check is recorded as BLOCKED_MECHANISM_CHECK. No selection and failed mechanism checks both give nonzero process exit. | The existing audit checks the selected layer in each held-out batch, implements both routes using the harness, and exports scalar maxima and derivative vectors. The 15 supplied tests use the fixture or synthetic tensors. Separate-process replay, an independent arithmetic check and single-prompt pretrained parity require additional evidence. |

The selected vector's sign follows the mean discovery activation and can differ from the sign of a particular held-out activation. Signed effects, top-1 counts and the six-control means are descriptive for these fixed prompts. The harness has no requirement for a positive held-out result or a top-1 change. A successful `MEASURED` exit alone cannot establish predictive performance, factual generalization or safety assurance.

No source correction follows from this static trace. Any load or parity discrepancy observed with the actual checkpoint should be retained at its original tolerances, with a separate run for any corrected implementation.
