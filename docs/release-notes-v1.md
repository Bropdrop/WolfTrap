# awooo evaluation distribution

WolfTrap remains the Apache-2.0 engine and Python distribution. This version adds a separately distributed pre-install verifier, an offline evaluation signing harness and write-once local artifact custody. The evaluation certificate authority exists solely for qualification. A production signing identity, external review witness, immutable public release service and trademark clearance are pending. The existing wheel version and CLI are preserved.

The supported installation matrix is Ubuntu 24.04 on x86-64 and arm64 with CPython 3.12.14. Matching hosted results identify the exercised platforms. Windows, macOS, other Python versions and standalone binaries are outside this release profile. Human onboarding duration and field accuracy are unmeasured. WolfTrap produces local static review evidence. Host authority and protected effects remain independently governed. Personal and commercial use remain free.

Use the separately trusted subscriber verifier before installing. Read the included verification instructions, license and security disclosure policy.
